# 지역예선 개선 계획 — 50선

> 작성일: 2026-07-12
> 대상: `hyunjoon-jin/worldcup` — 이미 구현된 지역예선(Q0~Q6) 위에서의 고도화
> 형식: 10개 테마 × 5개 = 50개 개선 항목. 우선순위 **P0/P1/P2** · 난이도 **S/M/L**

## 0. 현재 구현 요약과 개선 여지

예선은 **6개 대륙 조별 예선 + 대륙간 플레이오프 → 본선 48 확정 → 동적 포트 조추첨 연결**까지
동작한다(진출 확률·이변·규정 도움말 포함). 다만 실측 결과 다음 **근사/한계**가 있다.

| 영역 | 현재 상태 | 근거 |
| --- | --- | --- |
| 포맷 충실도 | 조 수가 근사(UEFA 8·CAF 6·AFC 4) | `qualification/index.ts` `CONFED_CONFIGS` |
| 진행 방식 | **일괄 결과**(버튼 한 번에 전체) — 라운드별 진행 없음 | `simulateAllQualification` 단발 |
| 능력치 반영 | **base 능력치만** 사용 — 샌드박스·컨디션 무시 | `index.ts:54` `baseRatingsMap(ALL_NATIONS…)` |
| 홈&어웨이 | CONMEBOL만 doubleRound, 나머지 단판 | `CONFED_CONFIGS` |
| 확률 계산 | 메인스레드 120회(setTimeout 청크) | `useQualificationStore` |
| 대륙간 PO 표시 | 리스트(브래킷 시각화 없음) | `QualificationStage` |
| 경기 상세 | 예선 경기 클릭 불가(본선만 모달) | 미구현 |
| 재현성 | 예선·조추첨은 시드 재현, **본선 경기는 Math.random** | `simCore` 진행 경로 |

## 특히 임팩트 큰 5선 (먼저 하면 좋은 것)

1. **D1 — 예선에 샌드박스·컨디션 반영**: 지금은 예선이 base 능력치만 써서, 샌드박스로 팀을
   키워도 예선 결과가 안 바뀐다. 본선과의 **일관성 결손**이라 우선 해소 가치가 크다.
2. **F1 — 예선 경기 상세 모달**: 본선은 경기를 눌러 상세를 보는데 예선은 못 본다. 재사용으로
   경험을 통일.
3. **H1 — 실제 조별 테이블 뷰**: 현재 대륙 전체 1열이라 "조별리그" 느낌이 약하다.
4. **B1/B3 — 라운드별 진행**: 일괄 결과 대신 관전 가능하게 하면 몰입이 크게 오른다.
5. **D5 — 확률 워커 이전**: 메인스레드 120회를 워커로 옮기면 반복수를 크게 올려 정확도↑.

> 이 문서는 기획서다. 실제 착수는 R1(일관성·완성도)부터 순차 진행을 권장한다.
