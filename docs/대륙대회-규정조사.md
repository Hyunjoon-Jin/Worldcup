# 대륙별 대표 대회(컨티넨탈 챔피언십) 규정 조사

> 목적: 월드컵과 동일한 수준으로 **6개 대륙 대표 대회**(유로·코파아메리카·아프리카네이션스컵·아시안컵·골드컵·오세아니아네이션스컵)를
> 시뮬레이터에 추가하기 위한 **1단계 — 대회 규정 정밀 조사**. 각 대회의 본선 포맷·조별 진출·녹아웃 구조·연장/승부차기·
> 조별 타이브레이커·예선 방식·조추첨/시드·역사적 변천을 웹 1차 출처(각 연맹 공식 규정, Wikipedia 등)로 교차 검증했다.
> (조사 시점 2026-07. 각 절 하단에 출처를 명시.)

**핵심 분기점 3가지 (구현 시 반드시 대회별로 분기):**
1. **조별 타이브레이커 순서** — UEFA·CAF·AFC는 **상대전적(H2H) 먼저**, CONMEBOL·CONCACAF·OFC는 **전체 득실차 먼저**(FIFA식). 월드컵 로직을 그대로 재사용하면 안 됨.
2. **연장 적용** — CONMEBOL·CONCACAF는 **결승에서만 연장**, 그 외 라운드는 90분 무승부 시 즉시 승부차기. 나머지 4개 대회는 전 라운드 연장.
3. **최고 3위 진출(와일드카드)** — 24팀 대회(유로·AFCON·아시안컵)만 사용. 16팀·8팀 대회는 조 1·2위만.

## 1. UEFA 유럽 축구 선수권 대회 (유로)

**본선 (유로 2024/2028/2032 동일):**
- **24팀**, **6조(A–F)×4팀**. 조별 단판 라운드로빈, **팀당 3경기**. 승점 3/1/0. 총 51경기.
- **진출:** 각 조 1·2위(12) + **최고 3위 4팀**(6개 3위 중) = **16** → R16.
- **녹아웃:** R16 → QF → SF → 결승. **3·4위전 없음**(1984년 이후 폐지).
- **연장:** 전 녹아웃 라운드 90분 무승부 시 **2×15 연장 → PK**.
- **조별 타이브레이커(H2H 우선, FIFA와 반대):**
  1. 동률팀 간 승점 → 2. 동률팀 간 득실차 → 3. 동률팀 간 득점 → 4.(부분 동률 시 1–3 재적용) →
  5. 전체 득실차 → 6. 전체 득점 → 7. 전체 승수 → 8.(최종전 2팀 한정 PK 특례) → 9. 징계 점수 → 10. 예선 랭킹.
- **최고 3위 R16 배정:** 4팀이 어느 조에서 나왔느냐에 따라 **C(6,4)=15가지 고정 대진표(룩업 테이블)**. 3위끼리 순위 매김은 대진에 무관하고 **출신 조 집합**만으로 결정. 3위는 항상 **B·C·E·F조 1위**와 대결.
- **예선:** 53개국 → 10개 조(5팀 7조 + 6팀 3조), 홈&어웨이. 각 조 1·2위 직행(20) + 개최국 + **네이션스리그 기반 플레이오프 3경로(각 4팀 준결·결승 단판) 승자 3팀** = 24. 개최국 자동진출은 **최대 2개국**까지 보장.
- **본선 시드:** 4포트×6팀, 예선 성적 랭킹 기반, 개최국 포트1 고정. (플레이오프 승자는 추첨 시점 미정→최하 포트)
- **변천:** 4팀(1960)→8팀(1980)→16팀(1996–2012)→**24팀(2016~)**.

출처: Wikipedia(UEFA European Championship / Euro 2024·2028·2032 / qualifying / knockout stage), UEFA.com, Goal, Football365, ESPN.

## 2. CONMEBOL 코파 아메리카

**본선 (코파 아메리카 2024):**
- **16팀** = **CONMEBOL 10개국(자동)** + **초청 6개국(최근 CONCACAF)**. **4조(A–D)×4팀**, 팀당 3경기. 승점 3/1/0.
- **진출:** 각 조 1·2위 = **8** → QF. (최고 3위 제도 **없음**.)
- **녹아웃:** QF → SF → **3·4위전 + 결승**. **3·4위전 있음.**
- **연장(핵심 특례):** **QF·SF·3위전은 90분 무승부 시 즉시 PK(연장 없음)**. **결승만 2×15 연장 후 PK.**
- **조별 타이브레이커(전체 득실 우선):** 1. 전체 득실차 → 2. 전체 득점 → 3. 상대전적(승점→득실→득점) → 4. 적은 레드카드 → 5. 적은 옐로카드 → 6. 추첨.
- **예선/참가:** CONMEBOL 10개국 전원 **자동 참가(예선 없음)**. 초청 6팀은 **CONCACAF 네이션스리그 연계 플레이인**으로 선발(2024: NL 8강 승자 4 + 패자 플레이오프 2).
- **본선 시드:** 4포트×4팀(2023-10 FIFA 랭킹). 포트1 4팀은 조 고정 배정(아르헨티나→A, 멕시코→B, 미국→C, 브라질→D).
- **주기:** 최근 4년(짝수, 유로와 정렬) 6–7월. 단 역사적으로 불규칙(하드코딩 권장: …2019, 2021, 2024, 2028).
- **변천:** 12팀 시대(1993–2015, 2019: 3조×4 + 최고 3위 2팀) ↔ **16팀(2016 센테나리오·2024: 4조×4, 최고 3위 없음)**.

## 3. CAF 아프리카 네이션스컵 (AFCON)

**본선 (2019~; 현행 = AFCON 2025, 모로코, 2025-12-21 ~ 2026-01-18):**
- **24팀**, **6조(A–F)×4팀**, 팀당 3경기. 승점 3/1/0. 총 52경기.
- **진출:** 각 조 1·2위(12) + **최고 3위 4팀** = **16** → R16.
- **녹아웃:** R16 → QF → SF → **3·4위전 + 결승**. **3·4위전 있음.**
- **연장:** 전 녹아웃 90분 무승부 시 **2×15 연장 → PK**. 어웨이골·골든골 없음.
- **조별 타이브레이커(H2H 우선):** 1. 승점 → 2. H2H 승점 → 3. H2H 득실 → 4. H2H 득점 → 5. 전체 득실 → 6. 전체 득점 → 7. 페어플레이 → 8. 추첨.
- **최고 3위 R16 배정:** 유로/구 월드컵과 동일 **15행 고정 룩업 테이블**(자기 조 팀과 안 만나도록). 3위 순위: 승점→전체 득실→전체 득점→페어플레이→추첨.
- **예선:** 예비 2연전(최하위 8팀→4 승자) + 44 직행 = 48팀 → **12조×4**, 홈&어웨이. 각 조 1·2위 = **24**(개최국 자동 포함).
- **본선 시드:** 4포트×6팀(FIFA 랭킹), 개최국 포트1 고정.
- **주기/시기:** **2년**. 시기 불안정 — 최근 12/1/2월(2021→2022, 2023→2024, 2025→2025.12~2026.1 실제 개최). **대회명 연도 ≠ 실제 개최 연도**.
- **변천:** …16팀(1998–2017: 4조×4, 곧바로 8강) → **24팀(2019~)**.

## 6. OFC 오세아니아 네이션스컵

**본선 (2024 기준):**
- **8팀** = 상위 7개국 시드(자동) + **예선 라운드 1팀**. **2조(A·B)×4팀**, 팀당 3경기. 승점 3/1/0.
- **진출:** 각 조 1·2위 = **4** → SF.
- **녹아웃:** SF → 결승. **3·4위전 에디션별 상이**(2024 있음 / 2016 없음). → **에디션 플래그로 처리(현행 기본값 '있음')**.
- **연장:** 90분 무승부 시 **2×15 연장 → PK**(표준 OFC/FIFA 규정).
- **조별 타이브레이커(전체 우선, FIFA식):** 1. 전체 승점 → 2. 전체 득실 → 3. 전체 득점 → 4. H2H 승점 → 5. H2H 득실 → 6. H2H 득점 → 7. 페어플레이 → 8. 추첨.
- **예선:** 최하위 회원국들이 **단일 라운드로빈(1개 개최지)** → 승자 1팀이 8번째 본선 티켓(2012·2016·2024 동일).
- **시드:** 직전 에디션 최종 순위로 포트 구성 후 2개 조 추첨.
- **회원:** OFC 13개(정회원 11=FIFA 회원, 준회원 2=키리바시·투발루 비FIFA). 호주는 2006 AFC 이적. **뉴질랜드 압도적 우세(역대 6회 우승)**.
- **주기/시기:** 불규칙(최근 ~2년), 년중(5–6월).
- **⚠ WC 예선 관계(정정):** 과거 에디션은 WC 예선을 겸했으나(2016=2018 WCQ 2라운드 겸용), **2024 네이션스컵은 2026 WCQ와 별개**로 분리 운영됨. → **'WC 예선 겸용' 여부를 에디션 플래그**로.

**신규로 만들어야 할 것(요약):**
1. 대회별 **포맷 정의 테이블**(팀수·조수·최고3위 여부·녹아웃 라운드·3위전 여부·연장 규칙·타이브레이커 종류).
2. **타이브레이커 2종**(H2H 우선 / 전체 우선)과 **연장 규칙 2종**(전 라운드 / 결승만) 파라미터화.
3. **24팀·16팀·8팀 브래킷 템플릿**(24팀은 기존 WT 슬롯 활용, 16팀·8팀은 신규 소형 브래킷).
4. 대회별 **예선/참가 모델**(대부분 간략화 가능; 골드컵·유로는 네이션스리그/플레이오프 근사).
5. **캘린더 배치**(월드컵 4년 주기 사이에 대륙컵 삽입 — 유로/코파/아시안컵 4년, AFCON/골드컵/OFC 2년).
6. UI: 대륙컵 탭/화면(조별·녹아웃·우승 연출), 팀 페이지에 대륙컵 성적·일정 추가.

## 8. 구현 난이도·범위 제언 (다음 단계 제안)

- **가장 재사용도 높은 것부터:** 유로·AFCON·아시안컵(모두 24팀·6조×4·최고3위 → 기존 월드컵 엔진과 거의 동형). 코파·골드컵(16팀·4조×4)·OFC(8팀·2조×4)는 소형 브래킷만 추가.
- **정확도 우선순위:** (1) 본선 포맷·조별 진출·녹아웃·연장/PK·타이브레이커 = 필수 정밀 구현. (2) 예선은 슬롯 수만 맞추고 포맷은 근사(월드컵 예선에서 이미 채택한 접근과 동일)해도 무방.
- **커리어 통합:** 월드컵 4년 주기 캘린더에 대륙컵을 시기별로 끼워, FIFA 랭킹(대륙컵 중요도 계수 이미 존재)과 팀 폼에 반영 → 대회 간 연속성 강화.

> 이 문서는 **1단계(규정 조사)** 산출물이다. 다음 단계에서 위 매핑을 바탕으로 **구현 기획안(데이터 모델·엔진 변경·UI·페이즈 분할)**을 작성한다.
