# 대륙별 대표 대회 — 예선(Qualification) 규정 조사

> `대륙대회-규정조사.md`(본선 포맷)의 **자매 문서**. 6개 대륙컵의 **예선 방식**을 대회별로 정밀 정리한다.
> 각 연맹 공식 규정·Wikipedia 등 웹 1차 출처 교차검증(조사 시점 2026-07). 시뮬레이터 구현 시 **예선 슬롯 수·경로·개최국 규칙**을 정확히 지키고,
> 세부 포맷은 필요에 따라 근사할 수 있도록 "정밀/근사" 우선순위도 함께 표기한다.

## 0. 한눈에 보는 예선 비교표

| 대회 | 참가국(예선) | 예선 구조 | 본선 티켓 배분 | 개최국 | WC예선/NL 연계 |
|---|---|---|---|---|---|
| **UEFA 유로** | ~53 | 10개 조(5팀 7조·6팀 3조) 홈&어웨이 + 네이션스리그 플레이오프 | 각 조 1·2위 20 + 개최국 + PO 3 = **24** | 자동(최대 2개국 보장) | **UEFA 네이션스리그** 기반 PO 3장 |
| **코파 아메리카** | 10 (+초청 6) | CONMEBOL 예선 **없음**(전원 자동) / 초청국은 CONCACAF 플레이인 | 10 자동 + 초청 6 = **16** | 참가국 중 선정 | CONCACAF NL 연계(초청 6장) |
| **AFCON** | ~52 | 예비 2연전(8→4) + 44 직행 = 48 → 12개 조×4 홈&어웨이 | 각 조 1·2위 = **24**(개최국 자동 포함) | 자동 | 독립(WC예선과 분리) |
| **AFC 아시안컵** | ~47 | **월드컵 예선과 통합** 1·2R + 아시안컵 전용 3R | 통합 2R 상위 18 + 개최국 + 전용 3R 6 = **24** | 자동 | **WC 예선과 초반 통합** |
| **CONCACAF 골드컵** | 41 | **네이션스리그** 성적 직행 + 골드컵 예비 2연전 + 초청 | NL 직행 8 + 예비 7 + 초청 1 = **16** | 참가국(대개 상위 시드) | **CONCACAF 네이션스리그**가 예선 파이프라인 |
| **OFC 네이션스컵** | ~11 | 최하위국 단일 라운드로빈 예선(1장) + 상위 7 시드 | 시드 7 + 예선 1 = **8** | 참가국 | 에디션별 상이(과거 WC예선 겸용) |

**구현 관점 3분류:**
- **월드컵 예선과 완전히 별개 & 자체 완결(정밀 구현 대상):** 유로, AFCON.
- **월드컵 예선/네이션스리그와 얽힘(연계 모델 필요):** 아시안컵(WC예선 통합), 골드컵(NL 파이프라인), 코파(CONCACAF NL로 초청국 선발).
- **초소형·자명(간단 구현):** OFC(예선 1장), 코파의 CONMEBOL 파트(예선 없음).

## 1. UEFA 유로 — 예선

**참가/구조 (유로 2024 기준):**
- **53개 협회 참가**(55 회원 − 개최국 자동 − 자격정지 러시아). 개최국 없을 땐 최대 54.
- **10개 조**: **5팀 7개 조 + 6팀 3개 조**. **홈&어웨이 더블 라운드로빈**(팀당 8~10경기).
- 진행: 대회 전년도 3·6·9·10·11월 더블 매치데이.

**본선 티켓 배분 = 24:**
- **각 조 1·2위 직행 → 20팀.**
- **개최국 자동진출**(2024 독일). UEFA는 **개최국 자동 슬롯을 최대 2개국까지 보장** — 공동개최가 3개국 이상이면(2028 UK&아일랜드 4개국) 개최국들도 예선을 치르되 **탈락 시를 대비한 예비 자동 슬롯 2장**만 확보.
- **네이션스리그 기반 플레이오프 3장:**
  - **12팀**이 참가(예선 직행 실패 팀 중 네이션스리그 순위 상위 그룹 우승팀부터 액세스 리스트 순으로).
  - **3개 경로(path)×4팀**. 각 경로 = **단판 준결승 2 + 단판 결승 1**(연장·PK 가능).
  - **각 경로 승자 1팀씩 = 3장.**
- 합계: 20(조) + 1(개최) + 3(PO) = **24**.

**본선 시드(예선 성적 기반):** 4포트×6팀, 개최국 포트1 고정. PO 승자는 추첨 시점 미정 → 최하 포트.

**구현 제언:** 조별 예선(10조)은 기존 조별 시뮬로 정밀 구현 가능. 네이션스리그 전체를 구현하기 부담되면 **PO 3장은 "예선 차상위 12팀 미니 토너먼트"로 근사**(NL 순위 대신 예선/랭킹 순위로 액세스 리스트 구성). 개최국 자동+예비 슬롯 규칙만 정확히.

출처: Wikipedia(UEFA Euro 2024 qualifying / play-offs / 2028), UEFA.com.

## 2. CONMEBOL 코파 아메리카 — 예선(참가 선발)

**CONMEBOL 10개국: 예선 없음 — 전원 자동 참가.** (회원이 정확히 10개국이라 10슬롯 상시 충족.)

**초청 6개국(2024 = CONCACAF):**
- 2023-01 CONMEBOL–CONCACAF 협약으로 비-CONMEBOL 6슬롯을 **CONCACAF 네이션스리그 연계 플레이인**으로 선발.
  - **CONCACAF 네이션스리그 8강 승자 4팀 직행**(미국·멕시코·파나마·자메이카).
  - **8강 패자 4팀**이 **단판 플레이오프 2경기**(2024-03) → 승자 2팀(캐나다·코스타리카).
  - 최종 초청 6: 미국·멕시코·파나마·자메이카·캐나다·코스타리카.
- **역사적 초청 방식:** 12팀 시대(1993–2016·2019)엔 CONMEBOL이 직접 초청(대개 멕시코 + CONCACAF 1팀, 1999·2019엔 일본·카타르 등 AFC).

**개최국:** 전통적으로 10개국 알파벳/로테이션. 특수사례로 오버라이드(2016 센테나리오 미국, 2024 미국 — 에콰도르 사퇴).

**구현 제언:** CONMEBOL 파트는 **예선 불필요(10팀 고정 참가)**. 초청 6팀은 게임 단순화를 위해 **CONCACAF 랭킹 상위 6 또는 골드컵/NL 결과 상위 6으로 근사** 가능. 커리어 통합 시 CONMEBOL은 "매 대회 전원 참가"라 관리 간단.

출처: Wikipedia(2024 Copa América / qualifying play-offs / Centenario), copaamerica.com, ESPN.

## 3. CAF 아프리카 네이션스컵(AFCON) — 예선

**참가/구조 (2025 예선 기준):**
- **참가 ~52개국**(CAF 회원 54~56 중 다수).
- **예비 라운드(Preliminary):** 최하위 **8팀**을 2포트×4로 시드(2024-02-15 FIFA 랭킹) → **홈&어웨이 2연전 4매치** → **승자 4팀** 진출.
- **조별 라운드:** 예비 승자 4 + 직행 44 = **48팀 → 12개 조×4**. 4포트×12(2024-06 FIFA 랭킹), 포트당 1팀씩. **홈&어웨이 더블 라운드로빈(팀당 6경기).**

**본선 티켓 배분 = 24:**
- **각 조 1·2위 = 24.**
- **개최국 자동진출**(2025 모로코). 개최국도 조별예선엔 참가하되 자리 보장 — 개최국이 조 1·2위에 들면 자동 슬롯이 **중복될 뿐 3위가 대체 진출하지 않음**(CAF 관행).

**예선 타이브레이커:** 승점 → H2H(승점·득실·득점) → 전체 득실 → 전체 득점 → 페어플레이 → 추첨.

**구현 제언:** WC 예선과 완전 별개라 **자체 완결형으로 정밀 구현 적합**. 예비 2연전 + 12조×4는 기존 엔진으로 직접 표현 가능. 개최국 자동 슬롯 중복 규칙만 주의.

출처: Wikipedia(2025 AFCON qualification), olympics.com, OneFootball(CAF 타이브레이커).

## 4. AFC 아시안컵 — 예선 (월드컵 예선과 통합)

**핵심: AFC는 월드컵 예선과 아시안컵 예선의 초반 라운드를 하나로 통합 운영.** (2027 아시안컵 = 2026 WC 예선 사이클과 결합.)

**참가:** AFC ~47개국 전원이 24 본선 티켓 경쟁. **개최국 자동진출**(2027 사우디, 1956년부터의 관행).

**단계별(2027 사이클):**
- **1R(WC+AC 통합):** 최하위권(~27–47위) 홈&어웨이 2연전 → **승자 10팀**.
- **2R(WC+AC 통합):** 상위 시드 26 + 1R 승자 10 = **36팀 → 9개 조×4**, 홈&어웨이. **각 조 1·2위(18팀)**가 WC 3R 진출 **& 아시안컵 본선 직행** → 첫 18슬롯(+개최국).
- **3R(아시안컵 전용):** 2R 각 조 3·4위(18) + 1R 최상위 패자 3 + 플레이오프 승자 3 = **24팀 → 6개 조×4**, 홈&어웨이. **각 조 1위 = 마지막 6슬롯.**
- 합계: 통합 2R 상위 18 + 개최국 + 전용 3R 6 = **24**.
- ⚠ **주의:** '아시안컵 예선 3R'(24팀·6조×4)과 동시 진행되는 'WC 예선 3R'(12팀·3조×4, 월드컵 슬롯용)은 **별개 대회** — 코드에서 혼동 금지.

**구현 제언:** 완전 통합 예선은 복잡. **아시안컵 관점에선 "월드컵 예선 2R 통과 상위 18 + 개최국 + 전용 3R 6"만 재현**하면 충분. 이미 이 시뮬은 AFC 월드컵 예선을 다단계로 모델링하므로, **그 2R 결과를 아시안컵 본선 직행 판정에 재사용**하고 전용 3R만 추가하는 방식이 자연스럽다.

출처: Wikipedia(2027 AFC Asian Cup qualification / third round / 2026 WCQ AFC), Xinhua(통합 포맷), the-AFC.com.

## 5. CONCACAF 골드컵 — 예선 (네이션스리그 파이프라인)

**핵심: 골드컵 본선은 CONCACAF 네이션스리그(CNL) 성적 + 골드컵 예비라운드로 채움.** 41개 회원국 전원이 CNL에 참가 = 예선 파이프라인.

**2025 골드컵 16슬롯 배분(모델):**
- **직행 8:** CNL **리그 A 8강 승자 4** + CNL **리그 B 조 1위 4**.
- **초청 1:** 사우디아라비아(2025·2027).
- **예비 통과 7:** 골드컵 예비라운드(2025-03) — **14팀이 홈&어웨이 2연전 7매치** → **승자 7팀**. (14팀 = CNL 하위권 + '네이션스리그 플레이인'(리그 C 상위 4 + 각 리그 A 조 5·6위) 승자 4로 구성.)
- 합계: 8 직행 + 7 예비 + 1 초청 = **16**.

**CONCACAF 네이션스리그 구조(예선 맥락):**
- **리그 A(16팀):** 4팀 8강 직행 + 12팀 2개 조(스위스식 4경기) → 조 상위 2 합류 → 8강 2연전 → Finals Four(준결·**3위전**·결승). **8강 승자 4팀 골드컵 직행.**
- **리그 B(16팀):** 4개 조×4, 홈&어웨이(6경기). **조 1위 4팀 골드컵 직행** + 승격.
- **리그 C(9팀):** 3개 조×3, 더블 라운드로빈.
- 승강제로 A↔B↔C 이동.

**시드:** 4포트×4(CONCACAF 랭킹), 포트1 조장 고정, 초청국 포트4.

**구현 제언:** CNL 전체 구현은 과함. **"CONCACAF 랭킹 상위 N개국 직행 + 나머지 예비 근사"**로 슬롯 16개만 정확히 채우면 충분. 커리어에서 네이션스리그를 별도 대회로 넣을지는 선택(넣으면 승강제 재미 추가).

출처: CONCACAF.com(2025 Gold Cup / NL), Wikipedia(Gold Cup qualification / Nations League), ESPN.

## 6. OFC 오세아니아 네이션스컵 — 예선

**참가/구조:**
- OFC 정회원 ~11개국(호주는 2006 AFC 이적).
- **예선 라운드:** **최하위권 회원국들이 단일 개최지에서 라운드로빈** → **승자 1팀**이 8번째 본선 티켓. 상위 **7개국은 시드로 자동 본선**.
  - 2024 예: 통가·사모아·쿡제도가 통가에서 단일 라운드로빈(2024-03) → 승자 1팀 합류.

**본선 티켓 = 8:** 시드 7 + 예선 1.

**시드:** 직전 에디션 최종 순위로 포트 구성 후 2개 조 추첨. 예선 승자는 미시드 슬롯으로 조 배정.

**⚠ 월드컵 예선 관계(정정 포함):**
- **과거 에디션은 WC 예선을 겸함**(예: 2016 네이션스컵 = 2018 WC 예선 2R 겸용 — 조 상위 3은 WCQ 최종 라운드로, 상위 2는 네이션스컵 준결승으로).
- **2024 네이션스컵은 2026 WC 예선과 별개**로 분리 운영. → **'WC 예선 겸용' 여부를 에디션 플래그**로 처리.
- 참고(2026 WCQ OFC 별도 구조): 1R(최하위 4팀 녹아웃 1장) → 2R(그 승자+상위 7 → 2개 조×4, 각 조 상위 2) → 3R(4팀 녹아웃, 승자 WC 직행·준우승 대륙간 PO). **OFC 사상 첫 월드컵 자동 직행 1장**(48팀 확대 덕분).

**구현 제언:** 예선 1장이라 **가장 간단**. "최하위 3~4팀 미니 라운드로빈 → 1장"만 재현하고 상위 7 시드. WC 예선 겸용 여부만 플래그로.

출처: Wikipedia(OFC Men's Nations Cup / 2024 qualification / 2018·2026 WCQ OFC), oceaniafootball.com, FIFA, NBC Sports.

## 7. 공통 구현 방침 (예선)

1. **슬롯 수는 정확히, 포맷은 필요 시 근사.** 월드컵 지역예선에서 이미 채택한 원칙과 동일 — 본선 참가국 수(24/16/8)와 개최국 규칙만 정확히 지키고, 예선 세부(라운드 수·경기 수)는 재미와 성능 균형에 맞춰 조정 가능.
2. **개최국 자동진출**은 모든 대회 공통 — 개최국을 예선에서 빼고 본선 시드에 선배치(월드컵과 동일 패턴, `hostContext` 재사용).
3. **연계 대회(네이션스리그 등)는 "근사 우선".** 골드컵 CNL·유로 PO·코파 초청국은 랭킹/직전 성적 기반 근사로 슬롯을 채우고, 원하면 후속 페이즈에서 정밀화.
4. **예선 타이브레이커**는 본선과 별개로 각 연맹 규정을 따르되, 본선 조사 문서의 **H2H우선/전체우선 2종 파라미터**를 그대로 재사용.
5. **커리어 캘린더 통합:** 유로·코파·아시안컵 예선은 4년 주기, AFCON·골드컵·OFC는 2년 주기로 월드컵 예선 사이에 배치. 예선 경기도 FIFA 랭킹(`qualifier` I=25 계수)에 반영.

> 이로써 **1단계 규정 조사(본선 + 예선)**가 완료된다. 다음 단계에서 이 두 문서를 근거로 **구현 기획안**(데이터 모델·엔진·UI·페이즈 분할)을 작성한다.
