# 월드컵 지역예선(대륙별 예선) 추가 — 순차 기획서

> 작성일: 2026-07-12
> 대상: `hyunjoon-jin/worldcup`
> 목표: 현재 "본선 48개국 확정" 지점에서 시작하는 앱에, 그 **앞단계인 대륙별 지역예선**을
> 추가해 "예선 → 본선 진출국 확정 → 조추첨 → 대회"의 전체 여정을 시뮬레이션한다.
> 형식: 의존성 순서대로 배치(Q0→Q6)한 **순차 실행 계획**. 각 단계는 독립 커밋/검증 가능.

---

## 0. 현재 구조와 재사용 가능한 자산

지역예선은 "더 많은 경기를 치러 48팀을 가려내는 과정"이므로, 이미 만들어 둔 자산을 크게 재사용한다.

| 자산 | 재사용 포인트 |
| --- | --- |
| `engine/matchCore.ts` (순수 경기 시뮬, #42) | 예선 경기도 동일 엔진으로 시뮬 — 대륙 무관 |
| `engine/simCore.ts` 패턴 | 스냅샷 기반 순수 시뮬 구조를 예선에도 그대로 적용 |
| `engine/tiebreakers.ts` | 조별 순위 결정(승점→상호전적→골득실…) 예선 조별리그에 재사용 |
| `engine/rng.ts` (시드) | 예선도 시드로 재현·공유 가능 |
| `store/useProgressStore`의 `phase` 모델 | 예선 phase를 앞에 추가하는 식으로 확장 |
| `data/teams.ts`의 `confederation`/`rank` | 대륙별 배정·시드 기준 그대로 활용 |
| 탭 구조(`App.tsx`) | "지역예선" 탭을 맨 앞에 추가 |

**가장 큰 선결 비용은 "예선 참가국 데이터"** 다. 현재는 본선 진출 48개국만 있으므로, 예선에 참가하는
**탈락 후보국들**을 추가해야 한다(아래 Q1).

## 실제 2026 대륙별 슬롯 배분 (기준)

| 대륙연맹 | 직행 | 대륙간 PO행 | 비고 |
| --- | --- | --- | --- |
| UEFA(유럽) | 16 | 0 | 12조 1위 직행 + 4장 유럽 PO |
| CAF(아프리카) | 9 | 1 | 9조 1위 직행 + 최고 2위 미니PO 승자 1팀 대륙간 PO |
| AFC(아시아) | 8 | 1 | 다단계, 최종 8직행 + 1팀 대륙간 PO |
| CONMEBOL(남미) | 6 | 1 | 10개국 단일리그 상위 6 직행 + 7위 대륙간 PO |
| CONCACAF(북중미) | 6 | 2 | 개최 3국 자동 + 3 직행, 2팀 대륙간 PO |
| OFC(오세아니아) | 1 | 1 | 1 직행 + 1팀 대륙간 PO |
| **대륙간 PO** | **2** | — | 6팀(AFC·CAF·CONMEBOL·OFC·CONCACAF×2) → 2장 |
| **합계** | **48** | | 46 직행 + PO 2 |

> 앱은 이 **슬롯 수**를 정확히 지키되, 각 대륙의 세부 포맷은 시뮬레이션에 적합하게 단순화한다
> (예: 조 수·경기 수를 규정에 맞추되 UI/연산 부담을 조절). 개최 3국(USA·MEX·CAN)은 예선 없이 자동 진출.

## Q0. 설계 확정 & 스캐폴딩 (P0 · S)

착수 전에 정해야 할 결정과, 이후 단계가 기댈 뼈대를 만든다.

- **결정 1 — 데이터 범위**: 전 세계 FIFA 회원(211) 전부가 아니라, **대륙별 현실적 경쟁국 풀**만
  모델링한다(예: UEFA ~28, CAF ~30, AFC ~24, CONMEBOL 10, CONCACAF ~20, OFC ~8). 규모를
  "슬롯보다 충분히 큰" 선에서 잡아 예선의 긴장감을 확보한다.
- **결정 2 — 본선 48 고정 vs 동적**: 예선 결과로 통과국이 실제와 달라질 수 있으므로, 본선
  **포트(pot)를 랭킹 기반으로 동적 계산**해야 한다(현재는 실제 드로우값 하드코딩). Q4에서 처리.
- **결정 3 — 진입 방식**: 예선을 항상 하는가? → "예선부터 시작" / "본선(실제 48)로 바로 시작"을
  **시작 화면에서 선택**. 기존 사용자 경험 보존.
- **산출물**: `types/qualification.ts`(타입), `data/confederations.ts`(슬롯 배분 상수),
  빈 `engine/qualification/` 디렉터리, 새 `useQualificationStore` 스텁, "지역예선" 탭 스텁.

## Q1. 예선 참가국 데이터 확장 (P0 · L)

예선을 돌릴 **선수(=국가) 풀**을 만든다. 이 단계가 전체 기능의 토대이자 최대 작업량.

- **작업**:
  - `data/qualifierTeams.ts` 신설 — 대륙별 비(非)본선 후보국을 `id·국명·iso2·confederation·rank`로 추가.
  - 기존 `teams.ts`의 48국과 **통합 뷰**(`ALL_NATIONS`) 제공: 본선 확정 여부와 무관하게 능력치는
    `ratingsFromRank`(#C1 곡선) 재사용 → 신규국도 랭킹만 있으면 능력치 자동 산출.
  - 국기: `country-flag-icons`에 있는 ISO2면 자동. 없는 소국은 대체 아이콘 규칙 정의.
- **산출물**: 대륙별 참가국 목록 + 랭킹. 기준일/출처 주석(#G1 규약 준수).
- **검증**: 대륙별 참가국 수 ≥ (직행+PO 슬롯) 단위 테스트, 중복 ID 없음.
- **리스크**: 데이터 정확도. "근사 랭킹"임을 명시(실제 대회 결과와 무관 고지 유지).

## Q2. 예선 포맷 엔진 — 대륙별 (P0 · L)

각 대륙의 예선을 **순수 함수**로 구현한다. `matchCore`/`tiebreakers`를 재사용하고, 대륙마다 포맷만 다르다.
스냅샷·시드 방식을 그대로 따라 재현 가능하게 만든다.

착수 순서(단순→복잡, 각각 독립 커밋):

1. **CONMEBOL (가장 단순)** — 10개국 단일 라운드로빈(홈&어웨이 18R) → 상위 6 직행, 7위 PO.
   *가장 먼저 구현해 "예선 엔진 골격"을 검증한다.*
2. **OFC** — 소규모 조별 + 결승 → 1 직행, 1 PO.
3. **CAF** — 9개 조(조별리그) → 조1위 9 직행 + 최고 2위 미니PO → 1 PO.
4. **UEFA** — 12개 조 → 조1위 12 직행 + 플레이오프 4장(조2위+네이션스리그 대체 경로 단순화).
5. **CONCACAF** — 개최 3국 자동 제외, 최종 라운드 조별 → 3 직행 + 2 PO.
6. **AFC** — 다단계(조별 → 최종 라운드) → 8 직행 + 1 PO.
7. **대륙간 플레이오프** — 6팀 → 미니 토너먼트 → 2 직행.

- **공통 산출물**: `engine/qualification/<confed>.ts` 각각 `simulate(snapshot, rand) → { qualified: string[], playoff: string[], standings }`.
- **검증**: 대륙별로 "직행 수·PO 수가 슬롯과 정확히 일치" 단위 테스트(각 대륙 1~2개). 총합 46+2=48 확인.

## Q3. 예선 스토어 & 진행 UI (P1 · M)

예선을 사용자가 "진행/관전"할 수 있게 한다.

- **작업**:
  - `store/useQualificationStore` — 대륙별 예선 상태(일정/결과/통과국), 시드, `phase: 'qualifying' | 'done'`.
  - "지역예선" 탭: 대륙 선택 → 조별 순위표/일정/통과 현황. 기존 `GroupTable`·`CalendarTimeline`
    컴포넌트 재사용.
  - 진행 방식: "대륙별 자동 시뮬" 또는 "라운드별 진행"(기존 일정 진행 UX 차용).
  - **내 팀 추적**(#D1 재사용): 내 팀의 예선 여정 강조("한국 최종예선 진출!" 등).
- **산출물**: 예선 탭 + 통과국 확정 화면.
- **검증**: E2E 스모크 확장(예선 자동 시뮬 → 48 확정 → 다음 단계 활성화).

## Q4. 예선 → 본선 연결 (동적 포트) (P0 · M)

예선 통과 48국을 기존 조추첨에 넘긴다. **핵심 통합 지점.**

- **작업**:
  - 통과 48국을 **FIFA 랭킹 기준으로 포트 1~4에 재배정**(개최 3국은 포트1 고정 — 기존 규칙 유지).
  - `drawEngine.createInitialDrawState`가 하드코딩 포트 대신 **주입된 포트 구성**을 받도록 리팩터링
    (현재 `getTeamsByPot`에 의존 → 파라미터화). 대륙연맹 제약 로직은 그대로 재사용.
  - "실제 48로 바로 시작" 경로는 기존 하드코딩 포트를 기본값으로 유지(하위호환).
- **산출물**: 예선 결과가 조추첨 풀로 흐르는 파이프라인.
- **검증**: 통과국으로 조추첨이 항상 완성 가능(백트래킹) 단위 테스트, 개최국 포트1 고정 확인.
- **리스크**: 대륙연맹 제약(UEFA 최대 2 등)과 동적 포트가 충돌해 조추첨 불가한 조합 → `isCompletable`
  백트래킹으로 이미 방어되나, 극단 케이스 테스트 필요.

## Q5. 확률·재현·샌드박스 통합 (P1 · M)

기존 고급 기능을 예선에도 확장한다.

- **예선 진출 확률**: 남은 예선 경기를 몬테카를로로 돌려 "본선 진출 확률"을 산출(#42 순수 엔진 재사용,
  워커에서 실행). 대시보드에 "예선 통과 확률" 뷰 추가.
- **시드 재현**: 예선+본선을 **하나의 시드**로 묶어 전체 여정 재현·공유(#C6 확장).
- **샌드박스**: 예선 단계에서도 능력치 조정 반영(기존 `getRatings`/스냅샷 경로 그대로).
- **검증**: 같은 시드 → 같은 예선 결과 재현 테스트.

## Q6. 콘텐츠·마무리 (P2 · S~M)

몰입 요소와 정리.

- **예선 드라마**: 이변 기사(#upsetArticle)·명장면(#D5)을 예선 경기에도 적용("최약체의 본선행" 등).
- **예선 통계·업적**: "무패 통과", "최종전 극장 진출" 등 업적(#46 확장).
- **온보딩/도움말**: 예선 규정 도움말(#G3 확장), 온보딩에 예선 단계 안내 추가.
- **문서/테스트 정리**: 대륙별 포맷 문서화, 회귀 테스트 총정리.

## 권장 진행 순서 (요약)

```
Q0 설계·스캐폴딩
      └─ Q1 예선 데이터(대륙별 참가국)         ← 최대 작업량, 토대
             └─ Q2 예선 엔진(CONMEBOL부터 대륙별)  ← 순수 함수, 엔진 재사용
                    └─ Q3 예선 스토어·진행 UI
                           └─ Q4 예선→본선 동적 포트 연결   ← 핵심 통합
                                  └─ Q5 확률·시드·샌드박스 통합
                                         └─ Q6 콘텐츠·마무리
```

**추천 첫 착수(수직 슬라이스)**: Q0 → Q1(우선 **1개 대륙만**, 예: 한국이 속한 **AFC** 또는 가장 단순한
**CONMEBOL**) → Q2 해당 대륙 1개 → Q3 최소 UI → Q4 부분 연결. 한 대륙으로 **전체 파이프라인을 끝까지
관통**해 설계를 검증한 뒤, 나머지 대륙으로 **가로 확장**하는 방식이 리스크가 가장 낮다.

## 핵심 결정 필요 사항 (착수 전)

1. **데이터 범위/정확도** — 대륙별 참가국을 어디까지(몇 개국) 넣을지, 랭킹 근사 허용 범위.
2. **첫 대륙** — 수직 슬라이스를 어느 대륙으로 시작할지(추천: 관심도 높은 **AFC**, 또는 가장 단순한 **CONMEBOL**).
3. **진입 UX** — "항상 예선부터" vs "예선/실제48 선택". (권장: 선택 제공)
4. **포맷 충실도** — 실제 규정 100% 재현 vs 슬롯만 지키는 단순화(권장: 슬롯 정확 + 포맷 근사).

> 이 문서는 기획서다. 실제 착수는 위 4개 결정 확정 후 Q0부터 순차로 진행한다.
> (사용자 요청에 따라, 이후 작업은 별도 지시가 있을 때만 main에 머지한다.)
