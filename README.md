# 2026 북중미 월드컵 시뮬레이터

캐나다·멕시코·미국이 공동 개최하는 2026 FIFA 월드컵의 조추첨부터 결승까지를 시뮬레이션하는
프론트엔드 전용 웹앱입니다. 실제 본선 진출 48개국과 실제 대회 규정(포트 구성, 대륙연맹 제약,
32강 진출 방식, 타이브레이커 등)을 기반으로 하며, 조추첨 이후의 모든 경기 결과는 가상
시뮬레이션입니다(실제 대회 결과와 무관).

## 주요 기능

- **조추첨**: 개최국 3팀 사전 고정 + 포트 1→4 순서로 대륙연맹 제약을 만족하는 무작위 조추첨을
  한 국가씩 진행
- **일정 진행**: 실제 2026 대회 일정 구조(그룹스테이지 6.11~6.27, 32강~결승 날짜창)를 기반으로
  하루 단위로 경기를 진행하고, 그날의 결과와 순위 변동을 확인
- **조별리그**: 조별 실시간 순위표, 조 상세 페이지(경기 일정/결과), 3위팀 횡단 순위표
- **토너먼트**: 32강(4 winner-runnerup + 8 winner-third + 4 runnerup-runnerup 구조)부터
  결승까지의 대진표
- **확률 대시보드**: 확정된 결과를 조건으로 남은 경기를 몬테카를로 반복 시뮬레이션하여 팀별
  조별통과/16강/8강/4강/결승/우승 확률을 실시간 산출
- **샌드박스 모드**: 팀별 공격/수비/컨디션 능력치를 조정해 시뮬레이션 결과에 즉시 반영

## 개발

```bash
npm install
npm run dev      # 로컬 개발 서버
npm run build    # 타입체크 + 프로덕션 빌드
npm run lint     # oxlint
```
